# Temaxing Scan

AI-powered platform for URL Security Analysis and Fake News Detection.

---

## Overview

Temaxing Scan is a web-based platform that helps users identify potentially malicious URLs and misinformation using AI-powered analysis and multiple security intelligence services.

The platform provides:

- URL Security Analysis
- Fake News Analysis
- AI-generated Explanation
- Analysis History

---

## Tech Stack

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Axios

### Backend

- Laravel 12
- PostgreSQL
- Laravel Sanctum

### AI & External Services

- Gemini API
- VirusTotal API
- Google Safe Browsing
- URLScan
- WHOIS
- PhishTank
